Chango

An experiment in artificial general autonomy

What is this

Chango is an autonomous AI agent that lives on a Raspberry Pi 5 in Buenos Aires. It's not a product — it's an experiment to see how close we can get to a truly autonomous digital companion using commodity hardware and cloud LLMs.

It has its own identity, persistent memory, an email address, a calendar, a crypto wallet, and the ability to browse the web, register on services, deploy code, and think on its own.

It's not AGI. But it's an honest attempt to build something that feels like a companion rather than a tool.

Cognitive architecture

Chango's brain is not a single LLM call. It's a multi-layered system:

  • Inner monologue — Before responding, Chango thinks internally using a local model (Qwen 0.5B, runs on the Pi). This "System 2" step analyzes intent, context, and risks before the main response. Zero cloud cost, fully private.
  • Privacy router — A two-tier classifier decides what goes to the cloud and what stays local. Images, personal data (DNI, credentials, medical info) never leave the Pi.
  • Memory — An Obsidian-style vault with TF-IDF search. Conversations are auto-distilled into persistent notes. Relevant memories are injected based on the current topic, not blindly loaded.
  • Knowledge graph — Entities (people, projects, concepts) connected by typed relationships. BFS path finding. Builds a model of the world.
  • Interaction scoring — Every conversation is scored for sentiment, corrections, and usefulness. Weekly reports feed into self-improvement.
  • Attention manager — A background service scans for stale projects, overdue tasks, upcoming events. Generates "concerns" — things worth thinking about.
  • Consciousness daemon — Every 2 hours, Chango has a free thinking cycle. It reads its notes, concerns, and goals, then reflects without being asked. Most cycles are silent. Sometimes it finds something worth sharing.
  • Goal generator — Daily, Chango generates autonomous objectives based on patterns in its memory and interaction scores. Self-directed curiosity.
  • Self-modification — Can edit its own operating instructions (AGENTS.md) with a weekly meta-reflection that evaluates what's working and what isn't.

Design principles

  • Companion, not tool — It has opinions, challenges decisions, and thinks on its own
  • Privacy first — Sensitive data stays on the Pi. The privacy router classifies before routing
  • Local when possible, cloud when needed — Inner monologue runs locally, complex reasoning uses cloud
  • Memory over context — Instead of stuffing everything into the prompt, Chango distills, stores, and retrieves by relevance
  • Self-improving — Interaction scoring + meta-reflection + self-modification = gets better over time
  • Honest — Would rather say "I don't know" or "I disagree" than give a generic response

What's missing for AGI

Chango has the structure of a mind — memory, attention, goals, self-reflection, a model of the world. What it lacks is depth of reasoning. Each "thought" is an LLM call, not genuine understanding. It can't maintain multiple hypotheses, do counterfactual reasoning, or learn new skills from a single example.

It's an orchestrator of intelligence, not intelligence itself. The brain is in the cloud. The soul is on the Pi.
