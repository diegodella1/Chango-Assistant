Insight: For automating SVS clip distribution, Instagram Graph API now supports Reels publishing for Professional Accounts (linked to FB Page). Flow: 1) Create media container with video URL, 2) poll status, 3) publish. Notes: video spec constraints (MP4/H.264, ≤15 min, size limits), captions/cover, scheduling via IG Content Publishing. Docs: https://developers.facebook.com/docs/instagram-platform/content-publishing/
