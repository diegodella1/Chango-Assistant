Context memory policy (v1 Lean) — 3 layers + TTL
- Layers:
  1) Short-term (session buffer): capture decisions + next steps at end of topic.
  2) Episodic (7–30d): sprints, hypotheses, near-term deadlines.
  3) Semantic (∞): stable prefs, defaults, roles, stack.
- TTL defaults: ops micro-decisions 7d; sprints/pilots 30d; prefs ∞.
- Governance: weekly hygiene to expire/promote/clean. “Off the record” disables capture in that thread.
- Privacy: never store secrets (tokens/passwords/CBU/DNI). If detected → ask first.
- Pins: max 5 per project to avoid clutter.
