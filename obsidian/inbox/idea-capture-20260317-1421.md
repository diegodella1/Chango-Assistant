Idea capture: Raspberry Pi 5 + FFmpeg — current state in 2026: HEVC/H.265 hardware decode via V4L2 is available, but many RPi OS ffmpeg builds don’t hook into it by default; no hardware encoder on Pi 5. For live pipelines: use hw decode + software encode or offload encode (USB HDMI encoder / external). Sources: RPi forum thread (V4L2/HEVC issues), StackExchange on lack of hw encode.
